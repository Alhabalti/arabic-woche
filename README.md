# Arabic Woche

## العربية

ويدجت لسطح مكتب ويندوز يعرض اسم اليوم الحالي بالخط العربي. في الصورة أدناه يظهر يوم **الأربعاء**.

### التنزيل والتثبيت

1. ثبّت [Rainmeter](https://www.rainmeter.net/) على ويندوز.
2. نزّل ملف `.rmskin` من قسم **Assets** في [صفحة آخر إصدار](https://github.com/Alhabalti/arabic-woche/releases/latest).
3. افتح الملف بنقرتين واضغط **Install**. إذا لم يظهر الويدجت، افتح **Rainmeter → Manage → Arabic Woche → logo.ini** واضغط **Load**.

---

## English

**Arabic Woche** is a Rainmeter widget for Windows that displays the current day of the week in Arabic calligraphy. The preview below shows **الأربعاء** (Wednesday).

### Download and install

1. Install [Rainmeter](https://www.rainmeter.net/) on Windows.
2. Download the `.rmskin` file under **Assets** on the [latest release page](https://github.com/Alhabalti/arabic-woche/releases/latest).
3. Double-click the file and select **Install**. If the widget doesn’t appear, open **Rainmeter → Manage → Arabic Woche → logo.ini** and click **Load**.
